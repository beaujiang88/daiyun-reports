二、核心打法：名单制 → 集中签约现场领机（本方案主菜）

2.1 新拓店链路（替代"一店一跑"）

集名单（30 天）→ 会前追单（14 天）→ 集中签约会·现场领机（1 天）
   → 30 天爆卡验收（每店一场）→ 裂变直推（持续）

2.2 四条关键设计

  1. 先购数果AI = 获机硬闸门：免费机器只给"已经投入、已经绑定工具"的店。899 元以上的前置投入同时解决三件事——过滤纯白嫖门店、给总部一笔首年现金流（对冲铺机与帮扶成本）、让门店从第一天起就有内容工具（出片/引流/交付都靠它）。这不是加价，是把软性福利换成了硬的准入门槛。
  2. 集中签约 · 现场领机：一场会让 20–30 家店一次性完成签约与领机授权。签约的当场把机器搬走（或现场发机/次日配送），仪式感就是最强的信任状——老板不怕被骗，怕的是"看不到别人也签"。
  3. 88 元定位费 + 现场定金：88 元是诚意筛选（可退可抵），现场签约收定金，配 7 天犹豫期。敢给退路，成交率反而更高。
  4. 领机 ≠ 发货：现场发的是"领机资格 + 编号 + 配送档期"，机器在门店跑通首场 227 爆卡后进场。风险敞口压到接近零，同时现场仪式感一点不减。

  • 到场率不足 60%：主会压缩到 3 小时，重点转 1v1；未到场店当天电话转线上签约。

  2. "0 风险"表述改为"0 押金 · 仪器免费入驻 · 全程培训带教"；资质与效果话术以实际检验报告为准。
  3. 医美项目必须由具备《医疗机构执业许可证》的机构 + 持证医师操作，门店不得自行操作医美；医美上提单独签协议。
  4. 直推抽成≤一层，写明"推广服务费"，单独签协议，不搞多级穿透。

5.8 能力边界（顾问必须知道，不许对门店乱承诺）

  • 能：批量出短视频（漫广 / 数字人口播）、批量出图文与话术、一键多平台发布、智能体助理做跟进提醒与经营小结；单人日产可达 3–5 条内容，成本近零。

5.9 合规红线（软件线专用）

八、待确认事项（做实方案的最后拼图）

在跑第一场签约会之前，这 8 项必须拍板：

设备与分润

  1. 设备实际采购价：16.8 万是标称价值，真实进货价决定回收周期与铺机节奏。
  2. 5-5 分的口径：是"爆卡帮扶业绩 5-5 分"，还是含日常会员卡全部流水？直接改写测算模型。
  3. 227 宠粉卡权益与履约成本：12 选 2 单项标价 1,980–3,980，核销率高 = 履约成本高，需测算每张卡实际服务成本（设备折旧 + 人工 + 耗材）。
  4. 设备检验报告：现有报告样品名为"CM1 型烟感""耐碱玻纤网格布"，与美容仪不符——对外展示资质前必须向品牌方（广西创正科技）索取与美容仪对应的检验报告。
  5. 980 医美会执行方：名医资源是总部自有还是第三方合作？决定医美上提的可控性与合规承接主体。
  6. 帮扶团队产能：现有几组成交老师、每月能排几场——这是规模化真正的瓶颈，比招商速度更硬。

数果AI（闸门）与团购

  1. 闸门退费口径（已定，写入合同）：年订阅制；开通 7 天内未交付可退，已交付不退。合同须与机器保证金、88 元定位费分开列账。
  2. 数果AI 直推结算：门店向同行销售，提成 200 / 400 元/单从软件款出还是从分润出？会员加购价 699 / 1,299 是否确认？
  3. 团购权益的边界：是否含美团/点评（还是仅抖音来客）？平台入驻资质用谁的（门店自有营业执照 / 总部代开）？团购券的收款与核销归谁、结算方式？赠送权益的有效期与续费价？
