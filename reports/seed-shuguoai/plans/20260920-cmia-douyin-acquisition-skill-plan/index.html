二、Skill 模块拆解（8 个，给开发用）

1merchant-scanner

职责：输入城市 + 品类（美业：美容/美甲/养生理疗/医美）+ 筛选条件 → 输出目标店家清单（店名、抖音号、团购销量、评分、是否已有短视频）。

数据来源（合规）：优先抖音开放平台/巨量本地生活服务商后台导出；手动整理则低频，禁高频爬虫（触发反爬封 IP/账号）。

输出格式：结构化 JSON，供 scorer 消费。

2merchant-scorer

职责：把原方案第二节「7 项排除清单」做成打分器，挑「有团购但内容少/更新慢、有基本盘缺爆点」的店（转化意愿最高）。

排除项（原方案口径）处理
3 个月以内新店 / 非美业 / 月业绩<2万 / 面积<50平 / 拓客卡<10张 / 配合度低 / 回款不清命中任一 → 降权或剔除，不触达

原方案原话：「月业绩低于 2 万不启动——官方要的是有基本盘、缺爆点的店。」

3sample-video-factory

职责：调本地数果AI 视频能力，为每家店生成 1–3 条「AI 短视频样片」+ 诊断报告（"同样的店，AI 生成的带货视频长这样"）。

对接：本地 3080 端口的 DSH 视频生成；可复用你已有的 qiaoben-gut-video-director 分镜/生视频流程。

4dm-copywriter

职责：按店家类型生成个性化私信草稿，话术锚定原方案「招商三笔账」。内置红线词过滤，自动拦截站外联系方式相关表述。

话术根（合规版）：「XX 店老板好，看到你们团购做得不错👍 我们给本地美业店做『免费铺 16.8 万仪器 + AI 帮你出短视频拿推流』，先免费给你跑一条样片看效果？感兴趣在抖音里回我『想看』就行。」
5comment-strategist

职责：在店家抖音视频下生成合规评论，引发店家主动私信你（而非你直接甩联系方式）。这是你问的"视频下留言让他加我们"的落地形态。

合规写法示例：「你们家这团购蛮实在的，我们专门帮美业店用 AI 出短视频引流，有几家店跑出过到店增长，有兴趣可以私信聊聊～」——只抛价值、留"私信"口子，绝不在评论里留微信/电话。

6lead-capture-sync

职责：对接企业号留资组件/私信自动回复表单，把店家主动填的微信/电话回写乔本客户系统（B 端门店档案），自动打标签 + 分配跟进阶段。

7followup-bot

职责：店家留资后，按原方案闭环阶段推送：样片 → 诊断 → 88 筛选 → 排 227 档期 → 仪器进场。跟进仍走企业号站内，或店家已在表单留微信后，再在微信深度聊（此时已合规）。

8compliance-guard（护栏）

职责：全局红线校验——发送前扫描任何「站外导流」意图（微信/电话/二维码/外部平台名），命中即拦截并提示改站内留资。这是把"规避"反过来做成"守规"的关键模块。

三、你纠结的核心：同音字 / 特殊符号，能不能用来规避封号？

结论：都不推荐，而且同音字/特殊符号是「最差」的选择。下面说清为什么，再给你能真正拿到联系方式的合规替代。

3.1 为什么同音字/特殊符号反而更危险

你以为的实际发生的
"薇信" "VX" "薇❤" 能绕过关键词抖音是语义级 AI 检测，不是关键词匹配。它识别的是"引导加站外联系方式"这个意图，不是具体字。变形字被识别为"刻意规避"，直接打高危导流标签——比正常发还容易封，且基本无解封。
符号隔开能骗过系统同样触发"恶意规避"判定，且评论/私信观感像 spam，店家警惕心重、转化低。
小号批量发个人号批量触达 = 秒封；矩阵号互导 = 连坐。
一句话：抖音的审核是"看你想干嘛"，不是"看你写了啥字"。任何变形都只是在告诉系统"我在故意绕你"——这比直说更该死。

3.2 真正拿到商家联系方式的合规路径（同样能拿到，账号能长期跑）

主路径：企业号 + 官方留资组件。这是抖音鼓励的行为（企业号核心功能），店家在你的主页点组件、填微信/电话，信息进企业号后台——平台不会判你站外引流，因为留资动作发生在抖音站内。

标准动作顺序：

  1. 私信/评论只抛价值 + 留「私信我/点主页组件」的站内口子；
  2. 店家主动在企业号留资组件填微信/电话（店家自己给的，不是你扒的）；
  3. 数据回传乔本系统 → 你再在微信里深度聊（此时已合规，是店家主动留的）。

这样：联系方式照样拿到，但全程在抖音规则内。品牌也立得住——你卖的是正经 AI 工具 + 免费铺机，不需要野路子。

3.3 如果你想"店家主动加我"，最稳的是内容种草

你发样片案例 + 本地话题，店家刷到主动私信你——这是零主动触达风险、转化率最高的获客方式。comment-strategist 的评论只是辅助钩子，主体流量靠样片内容。

四、合规引流六步（落地步骤）

① 扫描筛选→ ② 样片种草→ ③ 站内私信→ ④ 站内留资→ ⑤ 自动跟进→ ⑥ 数据回流
  1. 扫描筛选（数果AI）：城市+美业品类 → scorer 按 7 项排除清单排序，挑"有团购缺内容"的店。
  2. 样片种草（让店家主动来找）：sample-video-factory 出标杆样片，你企业号发 + 带本地话题。零主动触达风险。
  3. 站内触达（企业号私信）：对筛选店发个性化私信，话术只讲站内动作（"在抖音里回我"），不提任何站外联系方式。
  4. 站内留资（官方组件）：店家点企业号留资组件填微信/电话，进后台。compliance-guard 兜住任何越线话术。
  5. 自动跟进（数果AI）：留资后按 88→227→三美→980 阶段推送，站内或微信深聊。
  6. 数据回流：转化率反哺 scorer 模型，越跑越准。

五、账号安全红线（防封核心）

做法风险正确姿势
个人号批量私信极高，秒封用企业号，更高私信额度 + 留资功能
私信/评论塞微信电话二维码高危，站外引流用站内留资组件，店家主动填
同音字/符号规避反效果，标记高危不提站外，话术只讲站内动作
全自动群发脚本极高人工触发 or 企业号官方接口，低频个性化
高频爬虫抓商家反爬封 IP/账号官方导出 or 低频人工整理
节奏建议：单号单日私信 ≤ 20–30 条、间隔随机、内容差异化；新号先养 1–2 周（发自己内容、正常互动）再开始触达；准备 2–3 个企业号矩阵，单号出问题不影响整体。

六、数果AI 本地对接（Mac / DSH 3080）

skill 通过本地 3080 端口调用数果AI：

  • 样片生成：复用 qiaoben-gut-video-director 的分镜→生视频流程，喂入店家行业/团购卖点，产出 1–3 条样片。
  • 话术生成：dm-copywriter / comment-strategist 调本地 LLM，按三笔账模板生成个性化草稿。
  • 意图识别：followup-bot 读店家回复，分类（想看样片/问价格/已留资/拒绝）触发下一步。

所有"生成"在本地完成；"发送"不在此层，交给人工/企业号接口，合规分隔。

七、落地节奏（MVP 先跑最小闭环）

阶段做啥产出
Phase 1（骨架）merchant-scanner + merchant-scorer + dm-copywriter + compliance-guard能筛店、出合规私信、过红线
Phase 2（内容）sample-video-factory 接本地 3080 出样片样片种草可用
Phase 3（留资）lead-capture-sync 接企业号组件 + 乔本系统留资回写闭环
Phase 4（跟进）followup-bot + comment-strategist全自动承接（仍走站内）

Phase 1 即可跑通"筛店→出合规私信→人工发→看回复"的最小闭环，验证 scorer 命中率与话术回复率，再扩。

八、风险兜底

  • 账号被限流：2–3 个企业号矩阵，单号出问题不影响整体；
  • 留资合规争议：所有引导动作限定抖音站内组件，平台无理由封你"导流"；
  • 店家反感：话术以"免费样片/免费诊断"为钩子，降低侵入感；提供一键退订；
  • 样片翻车：先内部跑 3–5 家标杆，验证样片质量与到店增长数据再规模发。
