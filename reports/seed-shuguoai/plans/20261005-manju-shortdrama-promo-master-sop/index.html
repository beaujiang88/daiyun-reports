0. 一页纸：这份方案要你做什么

这门生意的本质一句话：给好的剧做分发，拿一个确定的百分比。 不是「随便剪剪就躺赚」——能不能跑出量，取决于剧本身和平台推流，不取决于你剪得多好【查证：新京报报道口径】。

你现在该做的三件事（按顺序，不许跳）：

  1. 选一条通道进场（优先快手「端原生短剧任务」——素材任务方给、授权天然解决、任务页未见粉丝门槛）【截图实证】
  2. 跑通 1 条合规成片（中视频 30s–10min，必须带解说/口播二创痕迹，不许大段拼接原片）【截图实证】
  3. 建台账 + 回收数据（不回收数据 = 纯体力活，产线永远不会变准）

三条铁律（违反任何一条，后面的活全部白做）：

铁律 内容
授权铁律 三平台正规通道都由版权方/任务方提供素材网盘，不需要交一分钱授权费。任何「交钱买授权/买代理」= 中间商加价或骗局【查证：抖音已把「引流收徒、兜售虚假运营技巧」列为违规】
素材铁律 未确认授权，绝不动剪；任务明令「只能用活动提供素材之外（内）的视频」时，我们自采的原片只能用于对标研究，不能进生产
合规铁律 时长、话题、挂载、聚合、排他条款逐条对照任务页；带擦边的题材即刻放弃（平台原话：切勿抱侥幸心理擦边）

预期管理（先压到最低）：

  • 快手实测任务：8660 条投稿，最高收益 7321.61 元——这是「最高」，绝大多数远低于此【截图实证】
  • 该任务奖金池 51.17 万，已瓜分约 80%，同类任务窗口期有限，进场要趁早【截图实证】
  • 行业切片成材率约 15%（100 人入行，月赚三四千约 15 人），该口径来自 2024 年真人短剧，不是漫剧口径【查证·有前提】
  • 快手最高收益「只能到抖音的零头」【查证：娱乐资本论】

2. 执行主线：11 阶段量产 SOP

① 选任务 → ② 素材获取与授权 → ③ 切片索引 → ④ 选题脚本 → ⑤ 粗剪
   → ⑥ 包装 → ⑦ 去重 → ⑧ 合规自检 → ⑨ 输出交付 → ⑩ 投稿(人工) → ⑪ 数据回收

关键认知：能自动化的是中间八步；头（拿任务/拿授权）和尾（投稿/回款）是人的事，谁也替不了。

阶段 ① 选任务 [人工] ⛔ 卡点：任务要求没抄全，不许开工

必须当场把下面字段抄进台账（漫剧星图/tasks.json）：

字段 为什么
任务方 / 剧名 素材来源与对账
结算口径（CPM/CPA/固定稿费/CPS/IAA） 决定往哪个方向优化
单价 / 分成比例 算得清才做
结算通道（是否开通云直通） 抖音侧：未开通只有 1%–29%
单条硬性要求（时长/挂载/话题/必带元素） 踩错 = 白剪
是否提供官方素材包 决定授权路径是否天然解决
有效期、投稿上限、多号可否重复投稿 决定排产节奏
排他条款 快手端原生任务：不可同时参加磁力聚星发文/小程序发文/巨星计划/小程序挂载

阶段 ② 素材获取与授权 [半自动] ⛔ 红线：不确认授权不动剪

优先级：任务方官方素材包（最优）＞ 获授权的原片 ＞ 自行采集（仅对标研究，或任务明确允许时）。

渠道能力（云端）：tools/scrape_douyin_user.py <sec_uid> → tools/batch_dl_by_title.py（playwm→play 拿无水印直链）。 ⚠️ 云端真实采集闭环未完整实测；且采集用于商业投稿素材必须先解决授权。

产出：漫剧星图/素材/<剧名>/ 下按集/片段归档的 mp4 + 来源与授权状态记录。

逐单用《素材授权确认模板》书面确认（见 §6.3），留聊天记录/邮件/任务页截图作凭证。

阶段 ③ 切片索引 [自动] —— 这是整条产线的核心资产

# 1) 台词转写（funasr SenseVoiceSmall，CPU；模型已缓存 897MB）
python3 tools/asr_transcribe.py 漫剧星图/素材/<剧名>/EP01.mp4
# 2) 按台词与静音切段（ffmpeg silencedetect 或按转写时间戳切）
#    粒度建议 3–8 秒，一个片段 = 一个可独立成立的「情绪单元」
# 3) 打标：开场炸点 / 反转 / 打脸 / 冲突爆发 / 情感高点 / 悬念钩子 / 人物关系交代

产出：漫剧星图/切片/<剧名>/index.csv

字段 例
clip_id EP01-0032
起止时间 00:01:12.400–00:01:18.900
时长 6.5s
台词摘要 「你凭什么替我做决定」
标签 冲突爆发
情绪强度 4/5
是否含敏感内容 否

有了这张表，之后每条混剪都是「按标签取片段拼装」，而不是每次重看原片。

阶段 ④ 选题与脚本 [半自动]

⚠️ 按快手一手实测修正：不要按短视频思维做。

  • 单条时长：10 分钟 > 时长 ≥ 30s（中视频）【截图实证】
  • 任务明令「禁止大段拼接/原片」，要求「明显二创痕迹」 → 脚本必须按「解说/口播二创」设计，不能靠拼片段【截图实证】

脚本模板（主力区间 1–3 分钟，最长不超 10 分钟；前 5 秒定生死）：

0–5s       开门杀：最强冲突 / 反常识的一句台词或解说，不带任何铺垫
5–20s      交代：谁、什么处境、什么困境（解说音轨为主，画面为辅）
20s–中段    冲突递进：每 15–30s 一次反转，长片可多次推进
结尾前      悬念留白：在最想知道结果的点切断，不给答案
最后 ≤30%   引导：口播/画面提示点击【底部合集】看全集

⛔ 卡点：不许剧透结局（既伤转化，也常是任务方明令禁止的） ⛔ 卡点：引导部分占比必须 < 全片 30%（快手任务原文，硬指标） 可复用底座：skills/02-漫剧超级编剧（选题/结构）＋ skills/03-狗血抓马漫广导演（钩子与冲突）

0–30 秒钩子结构（可用于正片节奏参考）【查证·来源为自媒体文章，未提供站内 A/B 数据】： 0–5s 开门杀（四句式挑一：反差 / 悬念 / 情绪 / 身份压制）→ 5–15s 三层递进钩子，每 3–5 秒递进一次 → 25–30s 不解谜，抛更大谜题承接下一集

阶段 ⑤ 粗剪 [自动]

工具：服务器 FFmpeg 4.4.2。按脚本给的时间段列表批量 trim → concat，统一分辨率与帧率。 产出：漫剧星图/工作/<条目标题>/rough.mp4 质检：30s ≤ 时长 < 10min（快手口径；其他平台按其任务页）、无黑帧、无音画错位。

阶段 ⑥ 包装 [自动]

python3 tools/autopack/autopack.py run \
  --video rough.mp4 --theme "<本条主题>" --level medium \
  --script script.txt -o packed.mp4

自动完成：字幕切句（句首=天然卡点）+ 音效时间轴 + 贴纸 + BGM。 质检：字幕错别字（用 ASR 反查一遍）、音效不盖台词、BGM 用素材库内曲目（不侵权）。

阶段 ⑦ 去重 [自动 · 本项需新建引擎]

⚠️ 2026-10-01 重要修正（快手实测）：任务原文禁止大段拼接/原片，要求明显二创痕迹 → 画面层去重不是重点，内容层二创才是重点。只做变速镜像，仍可能被判「简单裁剪拼接」。

分层处理（每层都动，不能只改一层）：

层 手段
画面 变速 / 镜像 / 裁剪构图 / 缩放比例 / 轻微旋转 / 色彩微调 / 加边框
音频 换 BGM / 换音效 / 加解说音轨（voice_tts） / 微调音高
结构 片段顺序重排 / 换开头钩子 / 改总时长
字幕 换字幕样式与位置
元数据 不同标题 / 不同封面 / 不同话题标签
  • 已知组合拳（有来源但非官方）：变速 0.9 → 抽帧 → 1.1 倍回速、镜像、比例裁切、加自制字幕/解说、换 BGM、片段重排
  • 平台明确说：没有任何方法保证 100% 去重，且查重机制会不断变化
  • 别做「饱和式铺量」：抖音禁止「工业化生产和批量发布同质化内容」，已上线账号健康分（初始 100，低分减少推荐/限制投稿/限制变现）
  • ⛔ 边界：去重是为了合规差异化，不是为了骗过审核去搬别人作品。前者是手艺，后者是封号路径。

阶段 ⑧ 合规自检 [半自动]

A. 任务硬性要求（快手实测任务原文，逐条打勾，缺一不可）【截图实证】

  • [ ] 带首话题 #快来看短剧（按具体任务页给的话题）
  • [ ] 时长 30s ≤ 时长 < 10min
  • [ ] 作品公开可见，不可设为隐私
  • [ ] 有明显二创痕迹（解说/口播/观点），无「大段拼接/原片」
  • [ ] 只用任务方提供素材（活动素材之外的视频一律不得使用）
  • [ ] 未同时参加磁力聚星发文 / 小程序发文 / 巨星计划 / 小程序挂载；未自行挂载其他 plc
  • [ ] 未聚合合集、未添加到现有合集（仅按任务要求引导【底部合集】）
  • [ ] 引导部分时长占比 < 全片 30%，图标占比不过大

B. 通用平台红线

  • [ ] 画面：血腥 / 擦边 / 恐怖 / 未成年不适画面
  • [ ] 台词：低俗 / 诱导充值 / 绝对化承诺 / 涉政涉赌
  • [ ] 内容与推广任务保持相关性（画面/字幕/音频都要对得上剧，防「挂羊头卖狗肉」被拒结）
  • [ ] 关键帧读图复核：image_recognize 看 6–8 帧（主模型看不见图，必须走这个）
  • [ ] 标题/封面与内容自洽（防标题党被限流）
  • [ ] 无刷单/刷量/虚假交易痕迹

阶段 ⑨ 输出交付 [自动]

落盘：/data/dsh-harness/media/漫剧星图/成片/<剧名>/<日期>-<序号>-<标题>.mp4 （必须落在媒体库根目录，否则预览 403） 命名规范、封面、文案、话题一并生成 copy.json。

阶段 ⑩ 投稿 [人工]

  • 按任务要求在 App 内本人完成投稿（挂载组件、带话题）——平台要求账号本人操作
  • 云端不代发（发布链路配置在 Mac 侧）
  • 投稿后立刻回写台账：投稿时间 / 视频链接 / 初始数据
  • ⚠️ 若考虑用数果聚合发布（蚁小二）代发，必须先验证「第三方通道发出去的视频算不算该任务投稿」（见 §7，目前完全未验证）

阶段 ⑪ 数据回收 [半自动] —— 唯一能让产线越跑越准的闭环

  • 3 天 / 7 天各取一次数据（播放、完播率、互动、结算状态）
  • 回写 tasks.json，产出「哪种钩子/标签组合跑得好」的结论 → 反哺阶段 ④
  • 不做这一步 = 纯体力活

3. 三平台规则速查（含硬数字与来源）

3.1 抖音 / 巨量星图（发行人计划线）

  • 分佣：普通任务固定 70%；专属任务 70%–90%；未开通云直通 1%–29%；个体达人平台服务费约 5%【查证：developer.open-douyin.com 官方公告】
  • 结算：星图账户无需预充值，按 用户有效付费金额 × 分佣比例 或 广告消耗金额 × 分成比例 结算【查证】

4. 内容打法（跨平台通用）

4.1 三条已被验证的形态

  1. 剧场号 + 单号锁垂直题材：头部剧场号均为「单账号聚焦垂直男频玄幻/诡异末世」，厂商普遍用剧场号集群布局【查证】→ 个人做号宜单号锁一个题材标签，不要什么都剪
  2. 解说/口播型（当前平台要求逼出来的必然选择）：平台明文要求明显二创痕迹 → 有解说音轨的作品天然比纯拼接更安全、更抗判重
  3. 标题模板化批量生产：剧场号标题反复出现「看了五分钟就陷进去」「看了第一集，想看第二集，打脸一波接着一波」「点击下方链接免费看全集」【本次抖音实测】——一个模板换剧名即可复用

4.2 去重的正确定位【查证】

一线操盘手原话：「去重逻辑是短剧分发最本质的东西，没什么爆款公式这一说」。但平台已把「工业化和批量发布同质化内容」写进违规清单——去重是合规差异化手艺，不是骗审核的技法。

4.3 发布节奏技巧【查证·来源为行业媒体，非官方】

  • 抢首发（首发达人原创度高、转化更好）
  • 爆了之后「先隐藏，过两天重新发一遍，及时收手」，防二次审核判违规

7.4 技术路线的结论

  • vphone（虚拟 iPhone 远程驱动）：结论是「否决」——原架构评估文件的判断是「大概率不通，建议放弃这条路」。三个硬约束都在你这台 Mac 上：① M4/16GB 内存跑 VM（默认 8CPU/8192MB/64GB 盘）会挤爆；② 须进 macOS 恢复模式改 SIP；③ Mac 须常开且进程不能被杀（已知进程被回收、端口漂移）。决定性证据来自项目自身文档/issue：商业 App 必崩或被 FairPlay 挡、多个相关 issue 均 closed as not planned、App Store 在 VM 内不工作、主二进制（微信 504MiB / TikTok 544MiB）启动即崩；唯一可用形态是越狱 VM，而反检测补丁自 2026-09-28 起默认关闭【查证】
  • 替代顺序（按推荐度）：① 蚁小二官方通道 + 真机/半自动（先验证「发布能否计入任务」，成本近零）→ ② 真机常驻 + 半自动 → ③ Android 云手机（阿里云无影 65–239 元/月，无 iOS）→ ④ 纯人工投稿（约 3 分钟/条）【查证】
  • Meta Muse：干不了这个活（四条理由：仅美加开放须 Meta 账号；跑在 Meta 美国云端、无 API 只能浏览器模拟，而快手核心发布在移动 App 且对境外 IP 风控极严；平台主动拦智能体；不解决两个真卡点——快手是否认可这种发布方式、以及 30s–10min 解说型二创的产能）。意外发现：Muse 的形态来自开源项目 OpenClaw（Meta 官方承认），架构是「harness + Markdown 配置文件」——我们自己的云端 DSH + AGENTS.md + 技能库/知识库就是同一形态，且更适配这个场景。唯一值得单拿的是 Muse Spark 1.3 已开放 API（兼容 OpenAI SDK、可走 OpenRouter、按 token 计费）【查证】

C.2 巨量星图：结算、验收与「保留期」坑【查证·星图§2.5、§3.1–3.5】

  • 未验收 7 个自然日自动验收
  • 客户侧服务费：指派·共创·招募·招商短剧 5%；投稿 10%
  • 个体达人扣 5%（10000 → 9500）；保底+佣金提现另付 3–5%
  • 短剧/小说小程序（2024-06-07 起）：云直通普通 70% / 专属 70–90% / 未开通 1–29%；广告分成 70% / 70–90%
  • 2026-09-20 起自动打款，仅绑银行卡；MCN 达人不可自行提现
  • 信用分初始 70（0–100），90 天行为数据周期
  • ⚠️ 保留期：默认 30 天，可设 15/30/60/90 天或自定义 ≤180 天；期内删除或设为「仅自己可见」会扣信用分 → 直接影响后续接单资格

C.3 快手：星任务 / 星视频 / 星火 的差别【查证·快手§1.2–1.7、§4】

  • 星视频 / 星直播＝CPT 一口价；星任务＝CPS / CPA / CPS+CPA，单次激活出价 0–100（2 位小数）
  • 关键红利条款：首次激活后 180 天内，该用户的付费 + 看广告收入全部分成（分成＝整体流水分成比例）【§1.5、§4】
  • 星火计划：广告分成 ≥70%，达人到手 = A × 分成比例 × 90%（平台收 10%）；每月 11–25 日收益 → 下月 1 日；上月 26–本月 10 日 → 本月 16 日
  • ⚠️ 税务变化：2025-10-01 起非对公结算按劳务报酬累计预扣法、提现代扣【§1.7】→ 到账金额会低于账面，排产时要按税后算
  • 报价三段式：1–20s ≤ 21–60s ≤ 60s 以上；星直播按小时 ≤ 按天；未落在推荐区间会限制接单【§1.6】
  • 广告内容 ≤ 整体视频 50%；电商/网服/游戏类前 10 秒无原创性禁【§5.2–5.3】
  • 禁「使用其他订单视频剪辑后完成任务视频」【§5.4】
