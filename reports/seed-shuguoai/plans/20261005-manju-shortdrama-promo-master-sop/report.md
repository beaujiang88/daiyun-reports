## 0. 一页纸：这份方案要你做什么

**这门生意的本质一句话**：**给好的剧做分发，拿一个确定的百分比。** 不是「随便剪剪就躺赚」——能不能跑出量，取决于剧本身和平台推流，不取决于你剪得多好【查证：新京报报道口径】。

**你现在该做的三件事（按顺序，不许跳）**：

1. **选一条通道进场**（优先快手「端原生短剧任务」——素材任务方给、授权天然解决、任务页未见粉丝门槛）【截图实证】
2. **跑通 1 条合规成片**（中视频 30s–10min，必须带解说/口播二创痕迹，不许大段拼接原片）【截图实证】
3. **建台账 + 回收数据**（不回收数据 = 纯体力活，产线永远不会变准）

**三条铁律（违反任何一条，后面的活全部白做）**：

| 铁律 | 内容 |
|---|---|
| 授权铁律 | 三平台正规通道都由**版权方/任务方提供素材网盘**，**不需要交一分钱授权费**。任何「交钱买授权/买代理」= 中间商加价或骗局【查证：抖音已把「引流收徒、兜售虚假运营技巧」列为违规】 |
| 素材铁律 | **未确认授权，绝不动剪**；任务明令「只能用活动提供素材之外（内）的视频」时，我们自采的原片**只能用于对标研究，不能进生产** |
| 合规铁律 | 时长、话题、挂载、聚合、排他条款逐条对照任务页；**带擦边的题材即刻放弃**（平台原话：切勿抱侥幸心理擦边） |

**预期管理（先压到最低）**：

- 快手实测任务：8660 条投稿，**最高收益 7321.61 元**——这是「最高」，绝大多数远低于此【截图实证】
- 该任务奖金池 51.17 万，**已瓜分约 80%**，同类任务窗口期有限，进场要趁早【截图实证】
- 行业切片成材率约 **15%**（100 人入行，月赚三四千约 15 人），该口径来自 2024 年真人短剧，**不是漫剧口径**【查证·有前提】
- 快手最高收益「只能到抖音的零头」【查证：娱乐资本论】

| 维度 | 快手星火计划 / 端原生短剧任务 | 快手磁力聚星 | 抖音短剧发行人计划 | 微信视频号短剧 CPS |

| 接什么单 | 小程序短剧 / 端原生短剧任务（广告+效果计费） | 品牌/客户任务（星任务/星视频） | 短剧/漫剧（**含红果出品的剧**） | 短剧 CPS（IAP） |

| 我方发布能力 | 数果聚合发布支持快手（扫码绑定，**但快手号尚未绑定**） | 同左 | 抖音有风控，需本人操作 | 待评估 |

### 1.2 推荐顺序【推断】

1. **快手端原生短剧任务 / 星火计划** —— 素材网盘制、无需预充值、结算节奏清晰、任务页未见粉丝门槛
2. **抖音短剧发行人计划** —— 门槛最低（有效粉 500 起），**且「做红果」的唯一真实入口就在这里**
3. **视频号 CPS / 磁力聚星** —— 有 1000 粉/关注后再作为补充

### 1.3 两个必须纠正的直觉

- **红果站内对零粉剪辑手，门是关着的**【查证】：红果官方可查的推广形态只有「红果演员双发」（对象是红果 App 内认证演员，给流量激励，**不是分佣**）；App 内金币/邀新玩法官方规则第 7 条**明确排除**公开拉新赚佣金。**想推红果的剧 → 去抖音发行人计划接「红果出品」的剧。红果是内容来源，不是接单入口。**
- **快手没有「抖音式短剧发行人计划」**【查证】：2023-12-31 快手已停止第三方微短剧小程序商业投放；未查到快手有发行人计划。**快手侧的达人分佣入口，实际就是「星火计划 / 端原生短剧任务」这一条。**

### 1.4 2026-10-05 抖音侧补充实测（本次新增）

抖音开放平台官方公告原文确认：**【短剧发行人计划】与【星图任务大厅】【小程序推广计划】三者并列**，同一条任务三处展示。分佣（官方原文数字）：

| 结算方式 | 任务条件 | 任务类型 | 分成比例 |
|---|---|---|---|
| 付费分佣 | 开通云直通 | 普通 | **固定 70%** |
| 付费分佣 | 开通云直通 | 专属 | **70%–90%** |
| 付费分佣 | **未开通云直通** | 普通/专属 | **1%–29%** |
| 广告分成 | — | 普通 | **固定 70%** |
| 广告分成 | — | 专属 | **70%–90%** |

> ⚠️ **选剧前第一件事：查该剧小程序的结算通道。** 没开通「云直通（企业版担保支付）」的，分佣只有 1%–29%，同样 10 万播放到手差 3–70 倍。这是绝大多数教学视频不会讲的一条。

站内样本实测（本次采集 86 条去重卡片）：**教学/流程/授权入口类内容占约 55%**，剧场号切片类约 20%，工具/供货约 12%。→ **供给端极度拥挤，真正的现金流在「教人做」与「给人供货」，不在自己剪片。** 样板账号：西哥自媒体（41.8 万获赞，一条业务拆 15+ 知识点）、贾哥自媒体（200.6 万获赞，授权入口型钩子）、迎春剧院（86.1 万获赞，剧场号标题模板）。

## 2. 执行主线：11 阶段量产 SOP

```
① 选任务 → ② 素材获取与授权 → ③ 切片索引 → ④ 选题脚本 → ⑤ 粗剪
   → ⑥ 包装 → ⑦ 去重 → ⑧ 合规自检 → ⑨ 输出交付 → ⑩ 投稿(人工) → ⑪ 数据回收
```

**关键认知**：**能自动化的是中间八步；头（拿任务/拿授权）和尾（投稿/回款）是人的事，谁也替不了。**

### 阶段 ① 选任务 `[人工]` ⛔ 卡点：任务要求没抄全，不许开工

必须当场把下面字段抄进台账（`漫剧星图/tasks.json`）：

| 字段 | 为什么 |
|---|---|
| 任务方 / 剧名 | 素材来源与对账 |
| 结算口径（CPM/CPA/固定稿费/CPS/IAA） | 决定往哪个方向优化 |
| 单价 / 分成比例 | 算得清才做 |
| **结算通道（是否开通云直通）** | 抖音侧：未开通只有 1%–29% |
| 单条硬性要求（时长/挂载/话题/必带元素） | 踩错 = 白剪 |
| 是否提供官方素材包 | 决定授权路径是否天然解决 |
| 有效期、投稿上限、多号可否重复投稿 | 决定排产节奏 |
| **排他条款** | 快手端原生任务：不可同时参加磁力聚星发文/小程序发文/巨星计划/小程序挂载 |

### 阶段 ② 素材获取与授权 `[半自动]` ⛔ 红线：不确认授权不动剪

优先级：**任务方官方素材包**（最优）＞ **获授权的原片** ＞ 自行采集（仅对标研究，或任务明确允许时）。

渠道能力（云端）：`tools/scrape_douyin_user.py <sec_uid>` → `tools/batch_dl_by_title.py`（`playwm`→`play` 拿无水印直链）。
⚠️ 云端真实采集闭环**未完整实测**；且采集用于**商业投稿素材**必须先解决授权。

产出：`漫剧星图/素材/<剧名>/` 下按集/片段归档的 mp4 + 来源与授权状态记录。

**逐单用《素材授权确认模板》书面确认**（见 §6.3），留聊天记录/邮件/任务页截图作凭证。

### 阶段 ③ 切片索引 `[自动]` —— 这是整条产线的核心资产

```bash
# 1) 台词转写（funasr SenseVoiceSmall，CPU；模型已缓存 897MB）
python3 tools/asr_transcribe.py 漫剧星图/素材/<剧名>/EP01.mp4
# 2) 按台词与静音切段（ffmpeg silencedetect 或按转写时间戳切）
#    粒度建议 3–8 秒，一个片段 = 一个可独立成立的「情绪单元」
# 3) 打标：开场炸点 / 反转 / 打脸 / 冲突爆发 / 情感高点 / 悬念钩子 / 人物关系交代
```

产出：`漫剧星图/切片/<剧名>/index.csv`

| 字段 | 例 |
|---|---|
| clip_id | EP01-0032 |
| 起止时间 | 00:01:12.400–00:01:18.900 |
| 时长 | 6.5s |
| 台词摘要 | 「你凭什么替我做决定」 |
| 标签 | 冲突爆发 |
| 情绪强度 | 4/5 |
| 是否含敏感内容 | 否 |

> 有了这张表，之后每条混剪都是「按标签取片段拼装」，而不是每次重看原片。

### 阶段 ④ 选题与脚本 `[半自动]`

**⚠️ 按快手一手实测修正：不要按短视频思维做。**
- **单条时长：10 分钟 > 时长 ≥ 30s**（中视频）【截图实证】
- 任务**明令「禁止大段拼接/原片」，要求「明显二创痕迹」** → **脚本必须按「解说/口播二创」设计，不能靠拼片段**【截图实证】

脚本模板（主力区间 1–3 分钟，最长不超 10 分钟；**前 5 秒定生死**）：

```
0–5s       开门杀：最强冲突 / 反常识的一句台词或解说，不带任何铺垫
5–20s      交代：谁、什么处境、什么困境（解说音轨为主，画面为辅）
20s–中段    冲突递进：每 15–30s 一次反转，长片可多次推进
结尾前      悬念留白：在最想知道结果的点切断，不给答案
最后 ≤30%   引导：口播/画面提示点击【底部合集】看全集
```

⛔ 卡点：**不许剧透结局**（既伤转化，也常是任务方明令禁止的）
⛔ 卡点：**引导部分占比必须 < 全片 30%**（快手任务原文，硬指标）
可复用底座：`skills/02-漫剧超级编剧`（选题/结构）＋ `skills/03-狗血抓马漫广导演`（钩子与冲突）

**0–30 秒钩子结构（可用于正片节奏参考）**【查证·来源为自媒体文章，未提供站内 A/B 数据】：
0–5s 开门杀（四句式挑一：反差 / 悬念 / 情绪 / 身份压制）→ 5–15s 三层递进钩子，每 3–5 秒递进一次 → 25–30s **不解谜，抛更大谜题承接下一集**

### 阶段 ⑤ 粗剪 `[自动]`

工具：服务器 FFmpeg 4.4.2。按脚本给的时间段列表批量 `trim` → `concat`，统一分辨率与帧率。
产出：`漫剧星图/工作/<条目标题>/rough.mp4`
质检：**30s ≤ 时长 < 10min**（快手口径；其他平台按其任务页）、无黑帧、无音画错位。

### 阶段 ⑥ 包装 `[自动]`

```bash
python3 tools/autopack/autopack.py run \
  --video rough.mp4 --theme "<本条主题>" --level medium \
  --script script.txt -o packed.mp4
```
自动完成：字幕切句（句首=天然卡点）+ 音效时间轴 + 贴纸 + BGM。
质检：字幕错别字（**用 ASR 反查一遍**）、音效不盖台词、BGM 用素材库内曲目（不侵权）。

### 阶段 ⑦ 去重 `[自动 · 本项需新建引擎]`

> ⚠️ **2026-10-01 重要修正（快手实测）**：任务原文**禁止大段拼接/原片，要求明显二创痕迹** → **画面层去重不是重点，内容层二创才是重点**。只做变速镜像，仍可能被判「简单裁剪拼接」。

分层处理（每层都动，不能只改一层）：

| 层 | 手段 |
|---|---|
| 画面 | 变速 / 镜像 / 裁剪构图 / 缩放比例 / 轻微旋转 / 色彩微调 / 加边框 |
| 音频 | 换 BGM / 换音效 / **加解说音轨（`voice_tts`）** / 微调音高 |
| 结构 | 片段顺序重排 / 换开头钩子 / 改总时长 |
| 字幕 | 换字幕样式与位置 |
| 元数据 | 不同标题 / 不同封面 / 不同话题标签 |

- 已知组合拳（有来源但非官方）：变速 0.9 → 抽帧 → 1.1 倍回速、镜像、比例裁切、加自制字幕/解说、换 BGM、片段重排
- **平台明确说：没有任何方法保证 100% 去重，且查重机制会不断变化**
- **别做「饱和式铺量」**：抖音禁止「工业化生产和批量发布同质化内容」，已上线账号健康分（初始 100，低分减少推荐/限制投稿/限制变现）
- ⛔ 边界：**去重是为了合规差异化，不是为了骗过审核去搬别人作品。前者是手艺，后者是封号路径。**

### 阶段 ⑧ 合规自检 `[半自动]`

**A. 任务硬性要求（快手实测任务原文，逐条打勾，缺一不可）**【截图实证】
- [ ] 带首话题 **#快来看短剧**（按具体任务页给的话题）
- [ ] 时长 **30s ≤ 时长 < 10min**
- [ ] 作品**公开可见**，不可设为隐私
- [ ] **有明显二创痕迹**（解说/口播/观点），无「大段拼接/原片」
- [ ] **只用任务方提供素材**（活动素材之外的视频一律不得使用）
- [ ] 未同时参加磁力聚星发文 / 小程序发文 / 巨星计划 / 小程序挂载；未自行挂载其他 plc
- [ ] 未聚合合集、未添加到现有合集（仅按任务要求引导【底部合集】）
- [ ] 引导部分**时长占比 < 全片 30%**，图标占比不过大

**B. 通用平台红线**
- [ ] 画面：血腥 / 擦边 / 恐怖 / 未成年不适画面
- [ ] 台词：低俗 / 诱导充值 / 绝对化承诺 / 涉政涉赌
- [ ] 内容与推广任务保持相关性（画面/字幕/音频都要对得上剧，防「挂羊头卖狗肉」被拒结）
- [ ] 关键帧读图复核：`image_recognize` 看 6–8 帧（**主模型看不见图，必须走这个**）
- [ ] 标题/封面与内容自洽（防标题党被限流）
- [ ] 无刷单/刷量/虚假交易痕迹

### 阶段 ⑨ 输出交付 `[自动]`

落盘：`/data/dsh-harness/media/漫剧星图/成片/<剧名>/<日期>-<序号>-<标题>.mp4`
（必须落在媒体库根目录，否则预览 403）
命名规范、封面、文案、话题一并生成 `copy.json`。

### 阶段 ⑩ 投稿 `[人工]`

- 按任务要求在 App 内**本人**完成投稿（挂载组件、带话题）——平台要求账号本人操作
- **云端不代发**（发布链路配置在 Mac 侧）
- 投稿后立刻回写台账：投稿时间 / 视频链接 / 初始数据
- ⚠️ 若考虑用数果聚合发布（蚁小二）代发，**必须先验证「第三方通道发出去的视频算不算该任务投稿」**（见 §7，目前完全未验证）

### 阶段 ⑪ 数据回收 `[半自动]` —— 唯一能让产线越跑越准的闭环

- 3 天 / 7 天各取一次数据（播放、完播率、互动、结算状态）
- 回写 `tasks.json`，产出「哪种钩子/标签组合跑得好」的结论 → 反哺阶段 ④
- **不做这一步 = 纯体力活**

### 产能估算（诚实版）

| 环节 | 单条耗时 | 说明 |
|---|---|---|
| 切片索引（一次性/剧） | 数小时 | 建库成本高，**可跨条复用** |
| 编码脚本 | 5–15 min | 熟练后模板化 |
| 粗剪 + 包装 | 5–10 min（机器） | 自动 |
| 去重 | 1–3 min（机器） | 待引擎落地 |

## 4. 内容打法（跨平台通用）

### 4.1 三条已被验证的形态
1. **剧场号 + 单号锁垂直题材**：头部剧场号均为「单账号聚焦垂直男频玄幻/诡异末世」，厂商普遍用剧场号集群布局【查证】→ 个人做号宜**单号锁一个题材标签**，不要什么都剪

### 7.4 技术路线的结论

### C.1 巨量星图：入驻与任务门槛是分开的【查证·星图§1.2–1.5】

**入驻本身无粉丝要求；门槛在「开通具体任务」上：**

| 任务类型 | 粉丝门槛 |
|---|---|
| 指派任务 | **≥10 万粉** |
| 直播投稿 | ≥1 千粉 ＋ 有效粉 ≥200 ＋ 近 14 天 ≥3 场、每场 ≥25min |
| 招募（一口价） | **1 万 ≤ 粉 ≤ 500 万** ＋ 有效粉 ≥500 |
| 星广联投 | ≥1 万粉 ＋ 有效粉 ≥500 |
| 星川 | 1 千 ≤ 粉 ≤ 100 万 ＋ 有效粉 ≥500 |

- 实名要求：**≥18 周岁**、禁未成年；**同一身份证/法人仅 2 个账号**；MCN 非必须【§1.3–1.4】
- 任务类型全景：指派 / 投稿 / 招募 / 星广联投 / 星川 / 直播投稿【§2.1】；短剧侧＝达人定制短剧（短剧招商广场）/ 抖音小程序分佣任务 / 短剧发行人计划 / 红果演员双发【§2.2–2.6】

### C.2 巨量星图：结算、验收与「保留期」坑【查证·星图§2.5、§3.1–3.5】

- **未验收 7 个自然日自动验收**
- 客户侧服务费：指派·共创·招募·招商短剧 **5%**；投稿 **10%**
- 个体达人扣 **5%**（10000 → 9500）；保底+佣金提现另付 3–5%
- 短剧/小说小程序（2024-06-07 起）：云直通普通 **70%** / 专属 **70–90%** / **未开通 1–29%**；广告分成 70% / 70–90%
- **2026-09-20 起自动打款，仅绑银行卡**；MCN 达人不可自行提现
- 信用分初始 **70**（0–100），90 天行为数据周期
- ⚠️ **保留期**：默认 30 天，可设 15/30/60/90 天或自定义 **≤180 天**；**期内删除或设为「仅自己可见」会扣信用分** → 直接影响后续接单资格
- ⚠️ PC 端**超 5 分钟不能绑定任务**
- 定制短剧：单集报价系数 **70%–120%**、下单 **2 集起**、服务费＝单集报价 × **5%**【§2.2】
- 媒体实证任务页硬要求：**时长 30 秒–20 分钟、全程带剧名**【§5.2】

### C.3 快手：星任务 / 星视频 / 星火 的差别【查证·快手§1.2–1.7、§4】

- **星视频 / 星直播**＝**CPT 一口价**；**星任务**＝CPS / CPA / CPS+CPA，**单次激活出价 0–100（2 位小数）**
- 关键红利条款：**首次激活后 180 天内**，该用户的付费 + 看广告收入**全部分成**（分成＝整体流水分成比例）【§1.5、§4】
- 星火计划：广告分成 ≥70%，达人到手 = A × 分成比例 × **90%**（平台收 10%）；每月 11–25 日收益 → 下月 1 日；上月 26–本月 10 日 → 本月 16 日
- ⚠️ **税务变化**：2025-10-01 起非对公结算按**劳务报酬累计预扣法**、提现代扣【§1.7】→ 到账金额会低于账面，排产时要按税后算
- 报价三段式：1–20s ≤ 21–60s ≤ 60s 以上；星直播按小时 ≤ 按天；未落在推荐区间会限制接单【§1.6】
- 广告内容 **≤ 整体视频 50%**；电商/网服/游戏类**前 10 秒无原创性禁**【§5.2–5.3】
- 禁「使用其他订单视频剪辑后完成任务视频」【§5.4】

### C.4 红果：除了「门是关的」，还有两条会咬人的规则【查证·红果§2.5、§4.5】
