1认识数果AI 云端工作台

它是什么、由什么组成、你最终能拿到什么。

1.1 一句话说明

数果AI 云端工作台是一台跑在云服务器上的 AI 员工工作站。你用浏览器打开一个网址、像发微信一样说需求，它就会在你的专属工作区里干活：写脚本、生视频、剪片子、加字幕贴纸、做封面、转写录音、整理知识库、批量下载素材、打包交付。

它最大的特点有三个：

不用装软件
任何设备打开浏览器就行——Windows、Mac、iPad、手机都能用，进度和文件都在服务器上，换台设备继续干。
有记忆、会成长
每个账号有独立工作区和知识库，攒下来的经验、套路、客户资料会沉淀下来，下次直接调用，不用重复教。
会自己找工具
它自带 59 项技能、70 多个工具脚本和 5700 多个素材，遇到任务会自己去调，不用你指定用哪一招。

2.3 会话区与余额

  • Workspaces（工作区）：显示你的账号工作区。工作区就是你的「私人电脑目录」，所有产物先落在里面。
  • 会话列表：按时间倒序列出历史对话，点一下就能接着聊。带 ⏱ 标记的是最近活跃的。
  • Balance / Today：实时费用与今日消耗（人民币）。旁边的小图标点开能看到更细的账单。
  • Peak · Off-peak（高峰/低谷）：显示当前计费时段，低谷时段计费减半，大批量任务可以安排在低谷跑。

3基础操作

七分钟跑通第一个任务，顺便把「怎么说话它才听得懂」讲透。

3.1 你的第一个任务

  1. 打开 https://dsh.sugoo.asia，用手机号 + 验证码登录。
  2. 点右下角 Continue 关掉测试声明。
  3. 在中间输入框里输入下面这句，直接发送：
    帮我写 3 条面向门店老板的口播脚本，每条 30 秒左右，主题是「用好 AI 短视频，门店不缺客」
  4. 等它回你（通常十几秒到一分钟）。它会直接给出脚本，并可能附上文件。
  5. 如果给了下载链接，点一下链接把文件存到自己电脑（这是最重要的一步）。
为什么要先做这个 这一步验证了三件事：登录通了、会话能发消息、文件能下载。三件事都通，后面所有功能才有可能。

3.2 怎么说话它才听得懂

它不需要你学任何语法，但说清楚四件事，成功率会从五成提到九成：

要素要交代什么例子
做什么最终产物是什么形态「一条 30 秒竖屏口播视频」「一份 Excel 表」「一套 9 张图」
给谁看受众是谁、什么平台「发给抖音上的 35-50 岁门店老板」
什么调性风格、情绪、禁忌「接地气、别太官方；不要出现医疗、功效类词汇」
有没有素材有没有参考文件 / 图片 / 链接「参考我上传的这张产品图」「按知识库里 08 号规范来做」

对比一下

✗ 不太好
「帮我做个视频」
—— 它只能靠猜，多半要来回追问好几轮，浪费你的时间。
✓ 好很多
「用这条口播文案做一条 30 秒竖屏数字人视频，背景用纯色，加上底部字幕，做完给我下载链接。文案：……」
一个实用技巧 不用一次说全。先说要什么产物，它会追问细节；或者先说「先给我出 1 条试试」，满意了再说「按这个风格再来 9 条」。这样比一次性长篇描述更省事。

3.3 上传文件与图片

  • 方式一：点输入框左下角的 +，选择本机文件。
  • 方式二：直接把文件拖进对话区。
  • 方式三：截图后直接粘贴（⌘V / Ctrl+V）。

支持的类型基本覆盖常用格式：图片（看字、识图、当参考图）、文档（Word / PDF / PPT / Excel）、音频（转文字）、视频（分析、剪辑、转数字人）。

限制项说明
单次上传大小上限100 MB。更大的文件请先用网盘或压缩包分卷。
图片能「看懂」图片内容、提取图中文字（有专门的视觉通道）。
音频 / 视频可以离线转成文字（中文准确率高，数字会自动规范化）。

3.4 引用文件与会话：@ 的用法

输入 @ 会弹出候选列表，可以引用：

  • 工作区里的文件——「@ 这个表，帮我按门店汇总一下」
  • 历史会话——「接着 @上次那条视频的脚本，改成 60 秒版」

用它比重新上传文件更快，也更不容易搞错对象。

3.5 斜杠命令：/ 的用法

输入 / 会列出可用命令（如新建会话、切换模型等快捷操作）。记不住也没关系，用中文直接说要干什么，效果一样。

3.6 换模型与推理档位

  • 输入框右侧显示当前模型，例如 DeepSeek-V4-Flash High。点开可以换。
  • High 代表更深的思考、更慢更贵；日常文案、整理类任务用默认档位就够。
  • 建议：除非遇到明显「答得不够好」的情况，否则不用动它。频繁切换反而容易让上下文变乱。

3.7 权限模式是什么（Workspace Write）

它代表它能动手改哪些文件：

模式含义
Workspace Write
推荐		只能在你自己的账号工作区内读写。既能完成任务，又不会碰到别人的数据。保持这个就行。
全盘访问模式能读写整台服务器。不要自己改——这是管理员级设置，会造成越权风险。

3.8 语音输入

点 🎤 后说话，自动转成文字填进输入框。首次使用浏览器会问「是否允许使用麦克风」，选允许。适合开车、走路或懒得打字时。

3.9 中途打断与继续

  • 想停下：回复过程中发送按钮会变成「停止」，点一下即可中断。
  • 说错了：直接发新消息纠正，例如「上面那条不要了，改成 60 秒版本」，它会以你的最新要求为准。
  • 关掉网页：长任务不会因此丢失。稍后回到同一个会话继续即可。

3.10 怎么拿到做好的东西（最重要的一节）

核心概念：产物在服务器上 它是在云服务器上干活的，文件先落在你的服务器工作区里。你在回复里看到的路径（如 /data/... 开头）不等于文件到了你电脑。拿到产物的唯一方式是——点它给你的下载链接。
  1. 任务完成后，它的回复里会带一个蓝色的下载链接，写着「下载 xxx.mp4」之类。
  2. 点它。浏览器会开始下载，文件存到你设备的默认下载目录。
  3. 手机上：文件一般在「文件」App（iPhone）或「下载」目录（安卓）里找。
  4. 多个文件时它会打成一个 zip 包，点一条链接下整包，解压即得。
  5. 如果回复里只有路径没有链接，直接说：给我下载链接。

详细说明、断点续传、微信里打不开怎么办，见第 7 章。

4功能模块详解

左侧每个入口：点开长什么样、能干什么、怎么操作、注意什么。

4.1 新建任务

项目说明
入口左侧第一项，或会话列表上方的 New Session
作用开一个干净的对话，不带之前对话的上下文
什么时候用换一件不相关的事时；或者发现它把两件事搞混了、答得开始跑偏时

4.2 Task Board · 任务看板

  • 是什么：一个轻量级的看板，把要做的事拆成卡片，分五列跟踪状态。
  • 五个列：Backlog（想法池）→ To Do（已排期）→ In Progress（在做）→ Done（完成）／Failed（失败）。
  • 项目筛选：左上角 Project 可以按项目分组（默认 All projects），适合同时盯几条业务线。
  • 怎么加：右上角 + New Task 手动加，或者直接在工作台里说「把这件事加到 Task Board 的待办里」。
  • 适合谁用：手上同时跑好几件事的人。单线程做一件事的话，不用管这个模块。

4.9 召唤智能体

智能体和技能的区别

技能（Skill）
像一本按需翻开的说明书：需要做某件事时，它才去翻对应那一章。你不用管，自动的。
智能体（Agent）
像一个常驻的专职员工：选中后，它全程以那个专业身份跟你说话、按那个身份的标准干活。

怎么召唤 / 切换

  1. 点输入框上方右侧的 🤖 智能体（默认） 下拉，或点右下角悬浮的「召唤智能体」。
  2. 从列表里选一个。选中后按会话记住，这个会话里它就一直保持这个身份。
  3. 想换回来，重新点开选「默认」即可。随时可换，不影响已有对话。

去哪找更多智能体

  • 左侧「应用市场」→ 智能体分类 → 安装。
  • 左侧「更多」→ 线上资源 → 平台市场。
  • 或者直接说需求，让它帮你找：有没有专门做口播文案的智能体？帮我装上
现成示范 工作台里已经预置了一个「数果智能体工程师」——如果你想要一个专属角色（比如「乔本门店督导」「越南市场顾问」），可以召唤它，直接说「帮我造一个 XX 智能体」，它会把包做好并装好。

6实战配方：十个高频任务

每个配方都是「照抄就能跑」的完整路径。

6.1 做一条数字人口播短视频

前提：需要先在数果平台完成形象克隆（一次性）。

  1. 准备文案。在对话里说：
    帮我写一条 30 秒口播文案，主题「门店没客流」，受众是 35-50 岁女装店老板，语气接地气，开头要有冲突感
  2. 确认文案。它会给你 1-3 版，你挑一版或提修改意见。
  3. 生成视频。说：
    用这版文案做一条数字人视频，竖屏 9:16，加底部字幕，做完给我下载链接
  4. 等待。几分钟到十几分钟。期间页面可以关掉。
  5. 拿片子。回复里会出现下载链接，点它，视频存到你本机。
  6. （可选）加包装。说「包装一下这条视频」，它会加贴纸、音效、BGM。
  7. （可选）做封面。说「给它配一个封面」，它会生成封面图。
一次只推进一步 新手最容易犯的错是一次性把六步全说完。先出文案 → 满意了 → 再做视频。这样每步都能叫停，不浪费算力和时间。

6.2 做一条 AI 漫剧广告

  1. 给它创意或现成剧本：把下面这个故事改成 15 秒漫剧广告，主角是便利店老板娘，参考图我上传了：……
  2. 它输出分镜脚本 + 生成提示词，先给你过目。
  3. 你确认后说：可以，去生成。它会提交到平台生成队列。
  4. 生成期间可以问进度：现在到哪一步了。
  5. 出片后它取回成片并给你下载链接。
合规红线（写剧本第一原则） 做健康、医疗、美妆类内容时，避开一切功效承诺与医疗敏感词（药名、成分、疗效数据、疾病治疗暗示）。产品做软植入，剧情是主角；对外发布前加「虚拟演绎 · 效果因人而异」标注。这条不是可选项。

6.3 给成片自动包装（字幕 + 贴纸 + 音效 + BGM）

  1. 上传视频，或者说「包装一下 /工作区里那条 xxx.mp4」。
  2. 说清调性：快节奏，年轻化，开头要一个抓人的音效。
  3. 它会自动选素材、对轴、渲染成片，完成后给链接。
  4. 不满意就说具体一点：字幕小一点，BGM 音量降到 25%，重跑即可。

6.4 生成封面 / 首帧

  • 说：给这条视频配一个竖屏封面，文案突出「3 天学会」，风格要醒目
  • 它会生成封面图并给你文件。封面上要写什么字，最好你直接给，比让它想更准。

6.5 做剪映能改字的字幕特效草稿

  1. 说：帮我做一套「逐字点亮」的字幕特效草稿，文案是第一句|第二句|第三句，导出成剪映能打开的包
  2. 它生成草稿包（zip）并给你下载链接。
  3. 下载 → 解压 → 放进剪映的草稿目录 → 打开剪映即可看到，文字可以自由修改。
两个边界 ① 剪映没有命令行渲染——能生成草稿，但不能自动导出 mp4，最后一步导片要在剪映里点。 ② 歌词样式等少数类型暂时不支持，问它会告诉你。

6.6 采集对标账号的全部作品

  1. 发账号主页链接，说：把这个号的全部视频下载下来，去水印，按标题命名，打包给我
  2. 它会拉起浏览器去采集。数量多时需要等一段时间。
  3. 完成后给一个 zip 下载链接。
请遵守平台规则与版权 采集来的内容只用于内部研究分析，不要直接搬运发布。二次创作要做足改动，涉及他人肖像、音乐、字体的要注意授权。

6.7 录音 / 视频转文字

  • 上传音频文件，说：转成文字，分好段落。
  • 中文准确率较高，数字会自动规范化（「三十」→「30」）。
  • 速度提示：30 秒音频在服务器上约需 1-2 分钟，慢在首次加载模型；连续转多个会明显更快。
  • 需要逐句时间戳（做字幕轴用）时说明一下，走的是另一条高精度通道。

6.8 把经验沉淀进知识库

  1. 说：把这次的经验整理成一份文档，准备归档到知识库
  2. 它会产出「待归档-主题-日期.md」放在你工作区，并给你下载/查看链接。
  3. 告诉管理员搬运（这一步只有管理员能做）。

6.9 做一份网页版报告

  • 说：把这份数据整理成一份 HTML 报告，要有图表，风格简洁专业，能直接打印
  • 产出是单个 HTML 文件，双击就能在浏览器看，⌘P 可存成 PDF。
  • 需要发给客户时，让管理员发布成公网链接（会员侧不能直接发布到外网）。

6.10 造一个专属智能体

  1. 点右下角「召唤智能体」，选择「数果智能体工程师」。
  2. 说：帮我造一个「乔本门店督导」智能体，职责是……说话风格是……
  3. 它会生成智能体包并安装，自检通过后即可在「🤖 智能体」下拉里看到。
  4. 下次开会话，选它，它就以这个身份跟你对话。

7交付与文件管理

这一章解决的是一句话：「它说做好了，可我没看到东西。」

7.1 为什么总说「给链接」

工作台运行在云服务器上，不是你的电脑。它做完的文件先存在服务器里你的专属目录，你的设备上暂时什么都没有。唯一通用的取件方式是浏览器下载。

所以它给你的回复长这样：

[下载 门店口播-01.mp4](https://dsh.sugoo.asia/__gw/download?path=...)

你要做的：点它。

7.2 三种拿文件的姿势

方式怎么操作适合场景
下载链接
首选		直接点回复里的蓝色链接绝大多数情况。单文件多大都能下。
文件管理面板打开后可以浏览、上传、下载工作区文件想自己翻目录、找之前的文件、或者批量下载
让我再发一次直接说「把 xxx 的下载链接再发我一次」链接丢了、记不清文件名、上次没存

7.3 文件太大 / 太多怎么办

  • 多个文件：让它打包。说「打成一个 zip 给我」，你只需要下一条链接。
  • 单个超大文件：直接下，服务器支持断点续传，中途断了再点同一个链接会接着下，不用从头来。
  • 上传上限：单次上传 100 MB。超过就先压缩或分卷。

7.4 下载常见问题速查

现象原因与处理
在微信里点链接没反应微信内置浏览器会拦截下载。点右上角「···」→「在浏览器打开」，再点同一个链接即可。
下到一半断了网络波动。重新点同一个链接，支持续传，不会从头开始。
手机上不知道存哪了iPhone：在「文件」App →「下载」里；安卓：文件管理器 →「下载」目录。

想直接传到服务器某个位置做不到，也不需要——你的工作区就在服务器上，产物本来就在那，缺的只是「拿到本机」这一步。

7.5 关于「数据放在哪」

  • 每个会员有独立的工作区，互相看不到对方文件，会话也是隔离的。
  • 共享的是知识库和素材库（团队公共资产），这是设计如此。
  • 重要产物建议下载到本机再备份一份，不要把它当成唯一存储。

8.1 当前确实做不到的事

8.2 常见问题 FAQ

问题回答
它半天不回我，是卡住了吗？长任务（生成视频、批量采集）耗时几分钟到十几分钟属正常。不要重复提交，重复提交会占算力。可以直接问「现在到哪一步了」。
它答得不对 / 跑偏了直接纠正，说清哪里不对。反复跑偏就新建会话重来，比在旧会话里纠缠更快。
页面关掉任务会丢吗？不会。任务在服务器上跑，回到同一个会话就能看到结果。
点「应用市场 / 资产库」弹登录框？正常。那几块是内嵌的数果平台页面，首次需用手机号单独登录一次数果账号。
知识库面板顶部有红色提示？那是面板附加小功能（问卷、备份按钮）的提示，知识浏览完全正常，忽略即可。
提示词该写多长？中文两三句到一小段都行。关键是说清「要什么产物 + 给谁看 + 什么调性」，不用写成长文。
可以同时做几件事吗？可以。开多个会话并行。但注意算力消耗，大数据量任务建议排在低谷时段（计费减半）。
怎么知道花了多少钱？左下角实时显示余额与今日消耗；也可以用 Task Board 与账单页看明细。建议给自己设个心理预算。
能把它的回答导出吗？可以说「整理成文档 / 表格 / HTML 给我」，它会产出文件给你下载。
它记得我之前说过什么吗？同一会话内完整记得；跨会话有长期记忆与知识库支撑，但重要背景建议明确说一次：「记住……」。
换设备后记录还在吗？在。所有内容都在服务器上，换个浏览器登录同一账号即可继续。
它会不会看到别人的数据？不会。工作区和会话按账号隔离；共享的只有知识库、素材库这类公共资产。

8.3 遇到报错怎么办

  1. 先刷新页面。多数临时问题刷新即恢复。
  2. 看它自己怎么说。把报错原文直接发给它：「这个报错什么意思，怎么办」——它有排障能力。
  3. 换个会话试。能区分「是你这个会话的问题」还是「整个服务的问题」。
  4. 两招都无效，说明可能是服务侧问题，联系管理员，并把这三条信息一起给他：你的账号、发生时间、报错原文（截图最好）。有这三条，定位通常几分钟内完成。
一句提醒 如果它说「做不到」，而你在第 5 章的清单里看到过这个能力，把你的需求再说具体一点再问一次。它有时只是没理解你要什么，而不是真不会。

D.2 会员开通后必查四项

  1. 技能数：问内核而不是数目录（数目录会被 .bak 和缺 frontmatter 骗到）。
  2. 插件数：开号模板与会员 profile 的 bundle 数应一致，且不含已下线包。
  3. 登录与隔离：会员只能进自己家目录，不能列举他人目录（租户隔离是设计，别为图省事放开）。
  4. 交付通路：下载接口能返回文件、支持断点续传（HTTP Range）。

D.3 三条运维纪律

  • 改前必备份，文件名带日期与用途（x.bak-YYYYMMDD-HHMMSS-用途）。
  • 长任务脱离 SSH 会话（setsid nohup … &），否则连接一断就留孤儿进程并互抢带宽。
  • app 升级后要重打本地补丁：打包版内核的多处容错补丁在升级后会丢失，升级完先跑一遍体检再放行。
